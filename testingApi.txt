================================================================================
                           TESTING ORDER RECOMMENDATION
================================================================================

Follow this order for complete testing:

1. Health Check (verify server running)
2. Auth: Signup → Login (save token)
3. Milk Rates: Create cow rate → Create buffalo rate
4. Animals: Create cows → Create buffaloes
5. Milk Collection: Create entries for different sessions/types
6. Expenses: Create various expense categories
7. Breeding: Create insemination records
8. Pregnancy Status: Update statuses through timeline
9. Notifications: Create and test notifications
10. Dashboard: View all reports and analytics

================================================================================
                                   PERIOD VALUES
================================================================================

For dashboard endpoints, use these period values:
- daily    : Today's data
- weekly   : This week (Sunday to Saturday)
- monthly  : This month
- yearly   : This year
- custom   : Custom date range (requires startDate & endDate)

================================================================================
                              PREGNANCY STATUS FLOW
================================================================================

Valid status transitions:
- check_pending → pregnant_confirmed
- check_pending → failed
- pregnant_confirmed → delivered
- pregnant_confirmed → failed

Terminal states (no further transitions):
- failed
- delivered
